# 🎓 School Financial Management System

A simple web-based school management system built with **JavaScript, Tailwind CSS, 
Cloudflare Workers, Google Sheets API, and Resend Email API**.

### Features

* Student Management
* Staff & Payroll
* Income & Expense Records
* Bank & Cash Book
* Uniform Inventory
* Financial Reports
* User Login & Role Permissions
* Backup & Email Export

### Technology

* HTML, CSS, JavaScript
* Tailwind CSS
* Cloudflare Workers
* Google Sheets API
* Resend Email API

### Security

* JWT Authentication
* Role-Based Access Control (RBAC)
* Secure API Access
* Automatic Backup
